# 서비스 소개

**ZONE-2**는 광역(**MBC충북**)과 기초(**옥천신문**) 뉴스를 결합하고, 이용자 반응을 AI로 2차 콘텐츠화하는 **지역 공론 디지털 미디어**입니다. 한국언론진흥재단 2026 지원사업.

## 한눈에

| | |
|---|---|
| 대상 지역 | 충청북도 옥천군(기초) · 충청북도(광역) |
| 매체 | MBC충북(광역) × 옥천신문(기초) |
| 핵심 가치 | 같은 사안의 **두 시선** 비교 + 주민 **여론 온도** + 음성 브리핑 |

## 두 개의 도메인

서비스는 두 주소로 접근합니다.

- **[mbcok.com](https://mbcok.com)** — **베타 프론트**. Threads 스타일의 새 디자인("이번 주 옥천"). 실 데이터(크로스뷰·팟캐스트)를 보여주는 시연/미리보기 판.
- **[www.mbcok.com](https://www.mbcok.com)** — **실앱**. 실시간 데이터로 동작하는 운영 버전.

::: tip 왜 두 개인가
`mbcok.com`은 정적 빌드 스냅샷(새 디자인 확정용), `www`는 크론으로 자동 갱신되는 실앱입니다. 자세한 배포 구조는 [운영](/guide/operations) 참고.
:::

## 무엇을 하나

1. **수집** — 광역·기초 매체의 기사와 주민 여론을 크롤링
2. **매칭** — 같은 사안을 다룬 광역·기초 기사쌍을 찾아 **크로스뷰** 생성
3. **온도 산출** — 주민 여론 신호를 이슈별로 모아 **공론 온도** 계산
4. **2차 콘텐츠** — 매일 음성 **팟캐스트**("오늘의 충북") 자동 발행
5. **공론** — 주민 의견·여론광장 글을 **공론장**에 모음

각 기능은 [주요 기능](/guide/features)에서 자세히 다룹니다.
