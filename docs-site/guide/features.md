# 주요 기능

## 🔀 크로스뷰

같은 사안을 **광역(MBC충북)과 기초(옥천신문)가 어떻게 다르게 보도했는지** 나란히 보여줍니다.

- 각 카드 = 광역 기사 + 기초 기사 한 쌍 + 두 시선을 요약한 **리딩 포인트**
- 원문 링크로 바로 이동
- "NNNN호 지면 보기" 같은 목차 페이지는 후보에서 자동 제외

**어떻게 만들어지나**: 임베딩 유사도 + 키워드 교집합 + 발행일 근접으로 후보를 찾고, 정제 후 `approved`된 쌍만 노출됩니다.

## 🌡️ 공론 온도계

이슈별로 주민 여론이 얼마나 뜨거운지 **온도(0~100)**로 보여줍니다.

- 여론 신호(댓글·여론광장 글)를 이슈 키워드와 매칭
- **빈도(시간 감쇠) · 감정 분산 · 토픽 집중도**를 합쳐 온도 산출
- 5구간: 잠잠(0–19) · 미온(20–39) · 보통(40–59) · 뜨거움(60–79) · 매우뜨거움(80–100)

::: warning 온도가 낮게 나오면
여론 표본이 적을 때는 온도가 낮게 나옵니다(정상). 여론 크롤 소스를 넓히면 신호가 풍부해집니다 — [데이터](/guide/data) 참고.
:::

## 🎧 팟캐스트 — "오늘의 충북"

매일 그날의 충북·옥천 소식을 묶어 **5분 음성 브리핑**으로 발행합니다.

- 대본 자동 생성 → 음성 합성 → 발행
- 대본 함께 보기(트랜스크립트) + 재생 중 문장 하이라이트

## 💬 공론장

주민 의견을 한곳에 모읍니다. 현재 **옥천신문 여론광장**의 실제 주민 글을 수집해 노출합니다.

## 📢 혜택·공고 <Badge type="warning" text="준비 중" />

옥천군청 **지원사업·모집·공고**(일자리·학자금·농업교육·재해보험 등)를 마감 임박순으로 보여줍니다. 수집은 가동 중이며, 화면 노출은 준비 중입니다 — [데이터](/guide/data#옥천군청-공고) 참고.
