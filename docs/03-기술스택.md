# 03. 기술 스택

> **실구현 안내(2026-10-25)**: 이 문서는 2026-07 원안이다. 실제 운영은 Cloudflare Workers 가 아니라 **Mac Studio self-host**(Next.js 15 `next start` :3002 + Docker Supabase + launchd 크론 + Cloudflare Tunnel)이며, AI 는 구독 CLI(codex)·Gemini TTS·로컬 감정 모델을 쓴다. 현재 스택은 [README](../README.md) 「실제로 쓰는 스택」이 기준이다.

> 서버 운영 없이 **서버리스 매니지드 스택**으로 구현한다. 목표 — 종량제 변동비 중심, 1~2인 개발로 10/30 시연 버전 완성.

## 1. 스택 요약 (Cloudflare + Supabase)

### Cloudflare
| 용도 | 서비스 |
|------|--------|
| 앱/SSR | Pages + Workers (Next.js, `@opennextjs/cloudflare`) |
| 서버 로직/API | Workers |
| 배치 스케줄 | **Cron Triggers** |
| 오디오·이미지 저장 | **R2** (S3 호환) |
| 캐시/세션 | **KV** |
| 파이프라인 큐 | **Queues** |
| AI 라우팅·캐싱·관측 | **AI Gateway** |
| 보안 | WAF + Bot Management |
| CDN/SSL | 내장 |
| 분석/로그 | Web Analytics + Logpush |

### Supabase
| 용도 | 서비스 |
|------|--------|
| 메인 DB | Postgres |
| 벡터 검색·매칭 | **pgvector** (HNSW) |
| 전문검색 | Postgres FTS |
| 실시간 push | **Realtime** (온도계) |
| 운영자 인증 | **Auth** |
| 파일 | Storage (대용량은 R2 우선) |

### AI / 외부 API
| 용도 | 서비스 | 경유 |
|------|--------|------|
| 매칭 재랭킹·요약·감정분석·스크립트·모더레이션 | **Claude API** | Cloudflare AI Gateway |
| 임베딩 | OpenAI `text-embedding-3-small` (또는 Voyage) | AI Gateway |
| TTS | OpenAI `gpt-4o-mini-tts` (백업 CLOVA) | AI Gateway |
| 영상 댓글 | YouTube Data API v3 | — |

### 프레임워크/라이브러리
- **Next.js 15** App Router (TypeScript) · **Tailwind CSS + shadcn/ui** · **Recharts**
- **AI SDK** (`ai`) — AI Gateway 라우팅
- **React Hook Form + Zod** · **pnpm**

## 2. 핵심 설계 포인트
| 기능 | 구현 방식 |
|------|-----------|
| 크로스뷰 매칭 | pgvector 코사인 Top-N 후보 → **Claude 재랭킹** → 상위 5건 |
| 감정 분석 | **Claude 배치 분류**(긍/부/중). 대량 시 Haiku로 비용 절감 + AI Gateway 캐싱 |
| 토픽/온도 | 임베딩 클러스터 + Postgres 집계 + 가중치 수식(α=0.4, β=0.35, γ=0.25) |
| 실시간 시각화 | Recharts 게이지 + **Supabase Realtime**(15분 갱신 push) |
| 팟캐스트 | Cron Triggers → Workers 파이프라인(Queues 단계 분리) → R2 저장 |

## 3. Cloudflare 특이사항 / 제약 ⚠️
| 항목 | 내용 | 대응 |
|------|------|------|
| **FFmpeg** | Workers는 CPU·시간 제약으로 FFmpeg 직접 실행 부적합 | 1차 단순결합/생략, -16 LUFS 필요시 외부 미디어 처리(컨테이너) 또는 클라이언트 측 |
| **Next.js 호환** | OpenNext for Cloudflare 일부 기능 제약 가능 | 호환성 검토, 필요시 프론트(Pages)+API(Workers) 분리 |
| **Workers 실행시간** | 장시간 작업 제한 | 팟캐스트 파이프라인은 Queues로 단계 분리 |
| **DB 연결** | Workers ↔ Postgres | `@supabase/supabase-js`(REST) 사용, 직접 TCP 풀 회피 |

## 5. 프로젝트 구조 (예정)
```
zone-2/
├─ app/
│  ├─ (public)/                 # 홈/crossview/temperature/podcast/forum
│  ├─ admin/                    # 관리자 대시보드
│  └─ api/                      # Route Handlers
├─ workers/
│  ├─ cron-ingest/              # 수집 (매시)
│  ├─ cron-match/               # 크로스뷰 매칭
│  ├─ cron-temperature/         # 온도 산출 (15분)
│  └─ cron-podcast/             # 팟캐스트 (월수금 07:00)
├─ lib/
│  ├─ supabase/  ai/  ingest/  matching/  temperature/  moderation/
├─ components/                  # shadcn UI
├─ supabase/migrations/         # DB 스키마
├─ scripts/report/eval-matching.ts     # 검증
├─ docs/  deliverables/
├─ open-next.config.ts          # OpenNext(Cloudflare)
└─ wrangler.toml                # Cloudflare 설정·크론·바인딩
```
