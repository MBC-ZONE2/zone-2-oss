# 01. 기능 정의서

> 1차년도 MVP 범위를 **기능 단위로 확정**한다. 각 기능은 입력 → 처리 → 출력 → 1차년도 포함/제외를 명시한다.
> 원칙: **AI 생성물은 자동 발행하지 않고 운영자 승인 후 게시.** 개인정보·명예훼손·혐오·허위정보 가능성 표현은 비식별화 또는 제외 처리.

## 기능 ① 크로스뷰 (Cross-View) — `필수`

**동일 이슈에 대해 MBC충북(광역 시각) × 옥천신문(기초 시각) 기사를 나란히 배치하고 AI로 요약·카드뉴스화한다.**

### 입력
- 양사 기사 (제목, 본문, 발행일, 카테고리, 키워드)

### 처리 (매칭 엔진)
1. **후보 생성**: 신규 기사 임베딩 → 반대 매체 기사와 `pgvector` 코사인 유사도 Top-N(예: 10건) 추출 (+ 발행일 ±7일, 키워드 교집합 필터)
2. **재랭킹**: 후보 N건을 Claude에 전달 → "같은 이슈인가?" 판정 + 매칭 점수 → 상위 5건 확정
3. **AI 요약**: 매칭된 기사쌍 → Claude로 ⓐ 광역 관점 요약 ⓑ 기초 관점 요약 ⓒ "같은 정책, 두 개의 현실" 대비 포인트 생성
4. **카드뉴스 생성**: 요약 텍스트 → 카드형 콘텐츠(1080×1350) 데이터 구성

### 출력
- 크로스뷰 페어 페이지: 좌(광역 기사) / 우(기초 기사) + AI Summary + Reading Point
- 카드뉴스 (SNS 공유용)
- 홈(모바일 릴스 덱)은 **표지 → 오늘의 충북 → 공론 온도 → 크로스뷰 최근 8쌍 → 옥천군청 공고 → 여론광장 → 끝** 순 고정 구성(최대 14장). 크로스뷰는 8쌍까지만 싣고(`HOME_CROSSVIEW_LIMIT`, `lib/reels/deck.ts`), 나머지는 끝 슬라이드의 「크로스뷰 전체 보기 →」로 `/crossview` 목록에서 이어 본다. 데스크톱 보드(`components/reels/desktop-board.tsx`)는 이 덱을 쓰지 않는 별도 구성이다.
- **내비는 검은 세계, 지면은 종이**(회의 결정 [8]): 데스크탑(≥1100px) 좌측 레일 `.side-nav` 와 그 하단 재생 도크는 모바일 하단 바와 같은 문법 — 배경 `#0b0d12` + 글자 `#f4f5f7`, 보조 설명 `#c3c7d1`. 레일 폭(220px)·좌표 계산·`--dk-nav 300` 은 그대로라 본문 판형은 바뀌지 않는다.
- **선택한 메뉴는 본문과 같은 색**(피그마 코멘트 #5·#9, 2026-09-11): 좌 레일에서 활성 항목(`[aria-current="page"]`)만 본문과 같은 종이 면 `--paper #f4f5f7` 블록 + 잉크 글자 `--ink #111` / 보조 설명 `--sub #5b6170` 이다. 종이 블록이 레일 폭 전체(오른쪽 여백 0)를 덮고 레일의 `border-right` 를 없애, 선택한 메뉴가 오른쪽 본문 지면으로 그대로 이어져 보인다. 기존 주황 세로 막대 4px 는 역할이 겹쳐 제거(투명 4px `border-left` 만 남겨 글자 시작선 유지). 고대비(`data-contrast=high`)에서는 `--paper` 가 검게 뒤집히므로 활성 항목을 백색 면 + 검정 글자로 반전하고 레일 경계선을 백색 1px 로 되살린다. (`app/reels.css`, `components/reels/nav.tsx`)
- **온도는 색으로도 읽는다**(피그마 코멘트 #6, 2026-09-11): 데스크탑 홈 보드(`components/reels/desktop-board.tsx`)의 크로스뷰 목록 행 메타와 우측 `TEMPERATURE` 레일 목록에서 **온도 낱말 + 숫자만** 밴드 색으로 칠한다(`data-band` → `app/board.css` 의 `--t-ink`). 매핑: 매우 뜨거움·뜨거움 = 수은 `#d90429`(매우 뜨거움은 굵기 800), 보통 = 잉크 `--ink`, 미온 = `--sub`, 잠잠 = `--faint-text`. 사안명·날짜·매체명은 색 밖이고, 빨강은 온도에만 쓴다. 수은의 밝은 끝 `#ff6b5e` 는 종이 위 2.6:1 이라 활자에 쓰지 않고 검은 세계·고대비에서만 쓴다.
- **크로스뷰 목록은 테두리 없이 활자로만**(피그마 코멘트 #12, 2026-09-11): `/crossview` 목록 행에서 광역·기초 제목 사이에 있던 **세로 괘선(유사도 점 레일)과 행마다 붙던 "보도 유사도 N%" 문구를 없앴다**(`components/crossview/crossview-card.tsx`, `app/crossview.css` `.cvp-vrule`·`.cvp-simdot` 삭제). 폰은 상하 스택, ≥640px 은 좌우 두 열(열 사이는 빈 종이 32px), 데스크탑 다단 격자 셀 안은 다시 상하 두 줄이다. 행 메타는 `2026.09.08 · ● 68° 뜨거움`(날짜 · 온도)만 남고, 유사도는 정렬 옵션 `매칭신뢰도순` 으로만 쓰인다(데이터·정렬 로직 무변경). 카테고리·정렬 탭은 가로 스크롤 스트립(`.cvp-tabs`: `overflow-x:auto` + `scroll-snap` + 스크롤바 숨김, 탭 타깃 44px).

- **같은 기사 중복 페어 차단**(2026-10-19, #188 `lib/matching/story`): MBC충북은 한 사안을 CMS 기사와 유튜브 영상으로
  **같은 제목**으로 두 번 내서, 옥천 기사 1건이 둘과 각각 페어가 돼 목록에 같은 사안이 연속으로 떴다. 제목을 정규화한
  storyKey(8자 이상)가 같으면 같은 기사로 보고, 한 옥천 기사에 대해 같은 story 의 MBC 페어는 하나만 둔다(매칭 단계에서
  후보 제외 — 뉴스 우선, 목록은 페이지 안 안전망, 기존 3그룹은 `scripts/ops/merge-duplicate-pairs.ts` 로 반려 정리·반려된
  페어 링크는 남은 페어로 리다이렉트). 다른 제목의 후속 기사는 별개 페어 그대로다.

- **푸터**(2026-10-21 대표 지시, `components/site-footer`): 한 부품 세 자리 — 홈 아닌 화면은 `.reels-page` 본문 뒤(온도계는
  검은 세계라 종이색 띠), 홈 모바일은 끝 슬라이드 맨 아래(덱은 끝이 있으므로), 홈 데스크탑은 보드 끝. 줄 1 로고·MBC충북 × 옥천신문·
  재단 CI(매체명은 각 사 홈 링크), 줄 2 소개(`/about`)·개인정보 안내(`/privacy` — 실제 저장 항목만 서술, 코드와 같게 유지)·문의(`FOOTER_CONTACT` 가 비어 있으면 생략), 줄 3 저작권. 관리자·위젯 링크 없음.
  공론장은 떠 있는 글쓰기 버튼 자리(오른쪽 112px)를 비운다.
- **홈 피드백 반영**(2026-10-19 대표): 표지의 개수 브리핑 띠(크로스뷰 N쌍·온도계 뜨거움 N°·오늘의 충북 N분)와 끝 슬라이드의
  "N장·N쌍" 문구를 뺐다. 데스크탑 홈의 크로스뷰는 괘선 목록 대신 **카드 스토리 격자**(2열, ≥1440 3열, 상위 6쌍 — 폰 덱과 같은
  4페이지 좌우 넘김 `components/reels/card-story`)로 보이고 나머지는 괘선 목록. 보드는 폰에서도 CSS 로 숨긴 채 마운트되므로
  하이드레이션 뒤 폰이면 스토리를 내린다.

### 발행 화자·출처 원칙
- 피드·목록·상세·알림·공유에서 글의 단일 발행자는 **`ZONE-2 크로스뷰`**다.
- ZONE-2가 두 보도를 읽고 비교·요약해 주민에게 직접 설명하는 편집 화자로 말한다. 원문 발췌를 그대로 ZONE-2 작성문처럼 붙이지 않고 `ZONE-2는 …를 확인했습니다`처럼 인용·종합 관계가 드러나는 문장으로 감싼다.
- MBC충북과 옥천신문은 작성자 자리에 번갈아 노출하지 않고, 본문 안의 광역/기초 관점과 **근거 출처**로 명확히 표시한다.
- 표현 순서: `ZONE-2 크로스뷰(화자) → 비교 설명 → MBC충북·옥천신문 원문 근거`.
- 매체 원문 제목·URL·발행일과 인용 범위는 그대로 보존해 ZONE-2의 발행 책임과 원출처의 저작권 귀속을 혼동하지 않는다.

### 1차년도 범위
- ✅ 포함: 키워드/임베딩 기반 기사 매칭, AI 요약, 카드뉴스, 운영자 검수 후 게시
- ❌ 제외(→2차년도): 영상(쇼츠) 자동 생성

### 검증
- 매칭 정확도 **Precision@5 ≥ 70%** (수동 태깅 정답셋 50쌍 대비 상위 5건 일치율, 7월)

## 기능 ② 지역 공론 온도계 (Issue Temperature) — `필수`

**양사 댓글·공론장 게시글을 분석해 이슈별 여론 온도(0~100)를 15분 단위로 시각화하고 TOP5 랭킹을 제공한다.**

### 입력
- 댓글/게시글 원문 (한국어), 최근 N일

### 처리 (4-Layer 파이프라인)
| Layer | 처리 |
|-------|------|
| L1 토큰화 | LLM 직접 처리 (형태소 분석 생략) |
| L2-a 키워드 빈도 | Postgres 집계 + 시간가중 decay λ=0.95 |
| L2-b 감정 극성 | **Claude 배치 분류** (긍/부/중 3-class) |
| L2-c 토픽 클러스터 | 임베딩 클러스터링 + Claude 라벨링 |
| L3 온도 산출 | `Score = α·Freq + β·SentVar + γ·TopicConc` (α=0.4, β=0.35, γ=0.25) |
| L4 시각화 | Recharts 게이지 + **Supabase Realtime** |

> 온도 산출 **수식(가중치 0.4/0.35/0.25)과 0~100 스케일**은 검증·보고서 일관성을 위해 고정한다.

**이슈 ↔ 여론 연결**(2026-10-11, #183 `lib/temperature/link`): 이슈 키워드를 댓글 본문과 substring 으로만 맞추던
규칙은 169사안 중 167사안이 댓글 0건이라 β(감정 분산)가 구조적으로 0 이었다. 이제 ① 키워드 → **지역 기사**(30일,
공고·전국 정치 클립 제외) → 그 기사의 댓글(`article_id`) 로 연결하고 ② 본문 키워드 매칭은 여러 낱말 키워드면
낱말 전부 포함으로 완화한다. 댓글 풀도 지역 기사 것만 쓴다(7일 365건 중 지역 36건). 분류한 감정은
`comments.sentiment` 에 저장해 재분류를 막고 공개 감정 분포(`/api/temperature/[issueId]`)도 같은 연결 규칙을 쓴다.
실행 통계는 `temperature_runs.stats`(matched·issuesWithOpinions·linkedArticles·pool·persisted). 첫 적용: 매칭 2→23건,
여론 있는 사안 2→18개.
**이슈 중복 방지**(2026-10-12, `lib/temperature/dedupe`): 매일 codex 가 뽑은 이슈가 기존 이슈와 같은 사안(정규화 키워드
공유 ≥ 절반, 또는 라벨 낱말 Jaccard ≥ 0.5)이면 새로 만들지 않고 키워드만 합친다. 라벨 문자열 일치만 보던 때는 169건 중
85건이 변형(송전선로 13건)이었고 `scripts/ops/merge-duplicate-issues.ts --apply` 로 84건으로 병합했다. codex 프롬프트에
기존 이슈 목록도 넣어 변형 재생성을 줄인다.

### 출력
- 이슈별 온도 게이지(0~100), 색상 그라데이션
- **기사 제목과 댓글의 활자 분리**(회의 결정 [6]): 크로스뷰 상세 댓글 타일 `.cvp-forum-tile` 은 댓글 본문 16px·이름/시각 13px 로 고정하고 행 전체를 왼쪽 44px(아바타 열) 들여쓴다 — 헤드라인(30/40px 700)과 단이 갈린다. 공론장 글 상세 `.fo-detail` 은 글 제목 26px 800 · 본문 18px(≥1440 19px), 댓글 16px + 왼쪽 44px 들여쓰기 + 옅은 인용 괘선. 모바일·데스크탑 공통(넓은 화면에서도 댓글 활자는 커지지 않는다).
- TOP5 핫이슈 랭킹 보드 (변동 화살표 포함) — 홈 온도 슬라이드의 사안명은 상세 링크(2026-10-19 피드백 "온도계 클릭 시 기사로")
- 사안 상세 `/temperature/[issueId]` 에 **관련 기사**(산출과 같은 연결 규칙 `lib/temperature/issue-articles`, 최근 30일 지역 기사
  ≤6건: 매체·날짜 → 제목=원문 링크 → 크로스뷰로 엮였으면 "크로스뷰 보기")
- 15분 단위 자동 갱신 (Realtime push)

### 1차년도 범위
- ✅ 포함: 감정분석 + 온도 산출 + 이슈 TOP5 + 15분 갱신 대시보드
- ❌ 제외(→2차년도): 개인별 맞춤 온도 알림

### 검증
- 15분 갱신 **정상 작동률 ≥ 95%** (Cloudflare Cron 성공률 / 서버 모니터링 로그, 9월)

## 기능 ③ AI 팟캐스트 "오늘의 충북(가칭)" — `필수`

**주요 기사 + 댓글·여론을 AI가 분석·종합해 3~5분 브리핑 스크립트를 만들고 TTS 오디오로 변환, 운영자 검수 후 웹에 게시한다.**

### 처리 파이프라인 (Cloudflare Cron 트리거)
```
1. Cron Trigger (월·수·금 07:00 KST)
2. 데이터 수집  : 최근 24h 기사 + 인기 댓글/게시글 TOP10
3. Merge/Dedup  : 중복 제거 (Postgres/pgvector)
4. Claude 호출  : 기사 요약 + 댓글 감정분석 + 스크립트 생성
                  (입력 ~3,000 tok / 출력 ~2,500 tok)
5. Script QA    : 금칙어 필터 + 팩트 룰 (정규식 + 사전)
6. TTS 변환     : OpenAI gpt-4o-mini-tts (약 7,500자 → ~5분)
7. (오디오 후처리: 인트로/아웃트로 병합 + 노멀라이즈 -16 LUFS)
8. Storage 저장 → 운영자 검수 큐(status=review)
9. 승인 시 ZONE-2 웹 게시
```
